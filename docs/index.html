One place for physical media

A catalog that understands the collection

Albumer treats every physical release as its own item while keeping the people, groups, and related editions connected.

Music and books

Catalog CDs, vinyl records, cassettes, and books with covers, notes, release years, and ownership status.

People and groups

People can be artists, authors, or both. Groups are assembled from artists and linked to their music.

Friendly search

Search ignores punctuation and formatting, so a query such as ostr still finds O.S.T.R.

Related releases

The same album on CD and cassette remains two separate items that can be connected as editions of one release.

Fast catalog views

Switch between grid and list layouts, filter by item type, medium, or status, and keep your preferred view.

Private by default

A single administrator login protects the catalog. Covers stay on your server and are not sent to an external service.

Connected data

Neo4j keeps relationships first-class

Albumer uses a graph because a collection is more than a list of titles. Artists create music, authors write books, people form groups, and physical editions relate to one another.

Run it on your server

A Go binary and Neo4j

Albumer ships as one Go application with embedded templates and assets. Neo4j runs as the separate database service, while the included installer can configure a Linux systemd service.

Read deployment guide 
# Requirements: Go 1.22+ and Neo4j 5+
git clone https://github.com/rtcoder/albumer.git
cd albumer

# Interactive Linux installation
./install.sh

# Or run locally
go run ./cmd/albumer
